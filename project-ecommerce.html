E-Commerce Website

A responsive e-commerce website that allows users to browse products, explore categories, search for products, view product details, and manage their shopping cart through an interactive and user-friendly interface.

Project Overview

This project is a complete front-end e-commerce website developed to provide a smooth and responsive shopping experience.

The website retrieves product data from the DummyJSON API and dynamically displays products, categories and product details.

I focused on building a clean interface, reusable components, responsive layouts and interactive features using JavaScript.

Technologies

HTML5 CSS3 Bootstrap JavaScript REST API DummyJSON API

Key Features

Product Listing

Displays products dynamically using data retrieved from the API.

Categories

Users can browse products based on different categories.

Search

Allows users to quickly find products through the search feature.

Product Details

Dedicated product details view with complete product information.

Shopping Cart

Users can add products to the cart and manage their selected items.

Responsive Design

Fully responsive layout for desktop, tablet and mobile devices.

My Role

I was responsible for designing and developing the front-end interface, implementing the interactive features, connecting the website to the API, handling product data and creating responsive layouts.

Project Highlights

  • Dynamic API integration
  • Product filtering and categories
  • Search functionality
  • Pagination
  • Product details
  • Interactive shopping cart
  • Responsive user interface
